# tvshowlibrary

A TV show tracking and episode calendar application.

## Overview

A web application for tracking TV shows and managing a personal episode-watching calendar. Uses FullCalendar for the episode schedule view, Drizzle ORM with Neon Postgres for data persistence, and Tailwind CSS for styling.

## Tech Stack

- Next.js 16 / TypeScript
- NextAuth.js with Google OAuth
- FullCalendar
- Drizzle ORM
- Neon Postgres (serverless PostgreSQL)
- Tailwind CSS
